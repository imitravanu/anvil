## 4. Architecture & safety assessment (V)

The lines that carry the properties, read directly this session:

- **Boundaries are mechanically enforced, not aspirational.** `@anvil/core` importing
  `@anvil/tui|cli` is caught three independent ways: gate Step 1 diff scan, Step 1.5 full-tree
  residual scan, and the self-contained pre-commit hook. The architecture claim lives in code a
  reviewer can check, not in a diagram.
- **The gate is a protected artifact.** `scripts/gate-manifest.json` pins SHA-256 for ten files
  (gate, constitution, allowlist, audit, sentinel, four workflows, pre-commit); Step 0.5
  verified them live — `Gate, constitution, allowlist, audit, sentinel, and CI hashes verified
  against manifest.` The sentinel test lives OUTSIDE the gate script, so weakening the gate is
  detectable from a process it does not control.
- **Path containment is symlink-aware, not string-prefix.** `tools/paths.ts:40-61` resolves the
  deepest existing ancestor through `realpathSync` before the containment check; the comment
  states the residual TOCTOU limit instead of hiding it.
- **The destructive-command guard is honest about what it is.** `tools/bash.ts:121-124`:
  "BEST-EFFORT PATTERN MATCHING, NOT A SANDBOX. It recognizes known destructive shapes; it does
  not enumerate every equivalent spelling… treat a pass here as 'not obviously destructive',
  never as 'proven safe'." The implementation matches the framing: `deshell()` (146-151) strips
  the `$IFS` family and fused-flag spellings; `isRootWipe()` (157-181) normalizes flag/target
  boundaries before matching.
- **Batch execution policy is fail-closed.** `agent/orchestrator.ts:36-38`: any mutating (or
  unknown) call forces the whole batch serial — single-flight prompts, no file/command races.
  The abort-listener attach/detach (44-56) is paired in `finally`, fixing the per-turn listener
  leak its comment documents.
- **Provider retries cannot replay.** `providers/base.ts:42-47` records whether any delta was
  surfaced and refuses retry after that point; retry/backoff limits come from
  `config/constants.ts`, not from inline literals.
- **Provider adapters are DRY.** `providers/groq.ts` is 15 lines over one shared
  ChatCompletions factory — twelve providers do not mean twelve copies of retry/stream logic.
- **TUI theme discipline is mechanical**: literal color strings are a scanner violation, and a
  component like `ContextGauge.tsx` (72 lines) derives every color through `useTheme()`.

## 5. Process assessment (V)

The differentiator is not the test count; it is epistemic discipline with receipts:

- `docs/CURRENT-FOCUS.md`: "A test counts as evidence only if it fails against the pre-change
  code"; "Probe before believing; discard an invalid probe rather than reason from it."
- Every phase fix carries a **mutation receipt** (W1: 10/10 assertions failed with the production
  files stashed, 10/10 passed after). Fail-first is the definition of evidence here.
- The changelog records **its own wrong verdicts** — the A/B harness's first "significant"
  result was shown to be fixture size, corrected in public with the reason and the corrected
  conclusion (no demonstrated benefit).
- Audits carry a status taxonomy (V = verified with quoted lines vs R = reported) so a reader
  knows what was personally probed.
- The constitution (`AGENTS.md` v2.2) is enforced by the gate, the hook, and the sentinel —
  rules with teeth, not a style guide.

This is the rarest asset in the repository. Code can be rewritten; a culture that demands
receipts is what keeps the rewrite honest.

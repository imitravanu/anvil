# Audit Record — 2026-09-06 (pre-0.6.0)

Full audit of the uncommitted Phase 11–15 wave before the v0.6.0 release:
static review of the whole diff plus live runs in a scratch `ANVIL_HOME`
(headless, goal mode, TUI) against real providers.

## Verified working (live)

- Headless `-p` with tool use; stdout/stderr separation; stdin piping;
  deterministic 404 → exit 1; `-y` gating and refusal messages.
- Closed-loop auto-repair: failing suite → edit → verification pass → exit 0.
- Cockpit header, theme picker, 429 countdown/retry UX, `/diff` modal,
  `/rewind` modal (rollback actually restored files), Mission Deck driven by
  the real goal engine (mixed ✓/✗ states, honest debrief).

## Found and fixed in this release

1. **Critical**: `verify_tests` pattern interpolation into `bash -c` — model
   could execute arbitrary shell through a non-mutating (permission-bypassing)
   tool. Proven with a canary file before the fix. Now: argv-array spawn, no
   shell.
2. TUI `/goal` was decorative — hardcoded deck, never updated, no engine.
   Now drives the real mission over the live session.
3. Auto-verification implemented but never enabled outside goal mode. Now on
   in TUI and headless chat sessions.
4. Goal engine marked every milestone completed unconditionally; empty
   critique verdicts printed; generic 3-phase plan for trivial goals; burned
   all turns after a permission refusal. All fixed (evidence-gated completion,
   verdict retry, scaled fallback, fail-fast).
5. Circuit-breaker accounting (double-counted 429s; 404s opened the circuit);
   `mutationsOccurred` counted missing outcomes as mutations; unborn-HEAD
   repos showed "no-git"; verification events invisible in headless output;
   verify_tests child stdin/env issues.
